# 飞书文档管理

## 做了什么

虾小丘管理开博尔的飞书文档体系：

| 任务 | 说明 |
|------|------|
| **FAQ 文档维护** | 客户常见问题按规范格式写入飞书知识库 |
| **开发更新汇总** | 每天自动拉 SDK 版本记录 + 各应用更新 |
| **文档索引系统** | 本地维护飞书文件索引，避免每次调 API |

───

## 核心思路

### 📋 FAQ 文档格式规范

所有 FAQ 内容都按统一格式写入：

```
## 章节标题 (H2)

### 小节 (H3，格式 1.x 名称)
#### 子节 (H4，格式 1.x.x)

**Q: [问题描述]**
**A: [答案，步骤用缩进列表]**

—— 分隔线 ——
```

───

### 本地索引优先策略

> 💡 查飞书文档先本地后远程，大幅减少 API 调用和 token 消耗。

```
用户要求查飞书文件
  → 先读本地 feishu-index/INDEX.md
    → 命中 → 直接用 doc_id 打开，跳过全局检索
    → 未命中 → 调 feishu API 全局搜索 → 找到后更新本地索引
```

───

### 每日开发更新汇总工作流

> 💡 用户说「昨日开发更新总结」→ 自动按固定流程执行。

| 步骤 | 做什么 |
|------|--------|
| 1 | 读取「DMP SDK版本开发记录」飞书文档 → 找昨天条目 |
| 2 | 遍历「应用更新记录」知识库的 6 个子页面 |
| 3 | 筛选昨天有更新的条目 |
| 4 | 按格式输出：SDK → 网易云 → Apple Music → 其他（标注「无更新」） |

**输出格式模板**：
```
📅 2026.05.xx 更新汇总

一、DMP SDK（系统 + 播放器 + Launcher）
- 分类列出每个开发者的更新要点

二、网易云音乐
- 条目

三、Apple Music
- 条目

四、其他应用（无更新）
- Kaiboer Home / K-link / 网络性能工具 / Curvora
```

## 🔄 复用指南

### FAQ 文档格式迁移

格式规范通用，换内容即可：

```markdown
# [产品名] 常见问题

## [章节编号] [章节名]
### [子节编号] [子节名]

**Q: [问题]**
**A: [答案]**

---

1. 操作步骤：[分步描述]
2. 操作步骤：[分步描述]
```

### 本地索引模式迁移

> 💡 查任何文档系统都先本地后远程，这个策略通用。

| 步骤 | 操作 |
|------|------|
| 1 | 搭建本地索引目录（如 `project-index/`） |
| 2 | 维护 `INDEX.md`（全量） + `by-tag.md`（按标签） + `metadata.json`（最后更新时间） |
| 3 | 每次用户检索，先 grep 本地索引 |
| 4 | 命中返回 ID/路径，未命中再调 API |
| 5 | 新找到的内容追加到索引 |

| 需要改 | 不需要动 |
|---------|---------|
| API 接口（飞书/Notion/Google Docs 等）、索引文件格式 | 本地优先策略、索引结构设计 |

**输出格式**：
[定义输出的结构]
