## 做了什么

虾小丘管理开博尔的飞书文档体系：

- **FAQ 文档维护**：客户常见问题按规范格式写入飞书知识库
- **开发更新汇总**：每天拉 SDK 版本记录 + 各应用更新
- **文档索引系统**：本地维护飞书文件索引，避免每次调 API

> [!IMPORTANT]
> 检索优先本地索引再远程 API，大幅减少调用次数和 token 消耗。

## 本地索引优先策略

> **检索流程**
>
> 用户要求查飞书文件
> → 先读本地 **feishu-index/INDEX.md**
> &nbsp;&nbsp;&nbsp;→ 命中 → 直接用 doc_id 打开
> &nbsp;&nbsp;&nbsp;→ 未命中 → 调 feishu API 全局搜索 → 找到后更新索引

本地维护三份索引：`INDEX.md`（全量）、`by-tag.md`（按标签）、`by-wiki.md`（按知识库）。每天凌晨 cron 自动增量更新。

## 每日开发更新汇总

用户说「昨日开发更新总结」→ 自动执行：

1. 读「DMP SDK版本开发记录」→ 找昨天条目
2. 遍历「应用更新记录」6 个子页面
3. 筛选昨天有更新的条目
4. 按格式输出：SDK → 网易云 → Apple Music → 其他（标注「无更新」）

> **📅 YYYY.MM.DD 更新汇总**
>
> **一、DMP SDK**（系统 + 播放器 + Launcher）
> — 分类列出各开发者更新要点
>
> **二、网易云音乐** — 条目
> **三、Apple Music** — 条目
> **四、其他应用**（无更新）— Kaiboer Home / K-link / 网络性能工具 / Curvora

## 复用指南

> [!TIP]
> **本地优先策略通用**。换 API 接口和索引文件格式即可。

1. 搭建 `project-index/` 目录
2. 维护 INDEX + by-tag + metadata.json
3. 用户检索先 grep 本地索引
4. 命中返回 ID，未命中调 API
5. 新内容追加到索引
